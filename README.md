# VitalIQ Web · Primera pantalla
Demo inicial React + TypeScript (Vite) y FastAPI. Roles visuales: superadmin, admin, usuario.
**No es autenticación real ni usar datos clínicos.**

Backend: `cd backend && python -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt && uvicorn app.main:app --reload`
Frontend: `cd frontend && npm install && npm run dev`
Abrir http://localhost:5173
